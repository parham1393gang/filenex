# FileNex — داشبورد فایل و مدیریت

FileNex یک پروژه Node.js و Express برای جست‌وجو و دانلود فایل با کد اختصاصی است. رابط کاربری فارسی و راست‌چین است و دو داشبورد جداگانه دارد.

## امکانات

- ثبت‌نام کاربران با کد ثبت‌نام `13931363` (قابل تغییر در `.env`).
- ورود کاربران و داشبورد شخصی شامل اطلاعات حساب، جست‌وجوی فایل و جست‌وجوهای اخیر ذخیره‌شده در همان مرورگر.
- داشبورد مدیر با آمار تعداد کاربران، فایل‌ها، نشست‌های مدیر و حجم فایل‌ها.
- مدیریت و حذف حساب کاربران؛ در مراجعه بعدی به سایت پیام «شما دوست پرهام حذف شدید» نمایش داده می‌شود.
- نمایش نشست‌های فعال مدیر و امکان لغو نشست‌های دیگر. نشست مدیر فعلی برای جلوگیری از قفل‌شدن پنل قابل حذف نیست.
- آپلود فایل از پنل مدیر با تأیید دوباره کد مدیر، تولید کد ۸ کاراکتری و حذف فایل‌ها از پنل.
- محدودیت نوع و حجم فایل، محدودیت تعداد درخواست‌ها، هش امن رمز عبور و کوکی نشست HttpOnly.
- فایل‌ها و اطلاعات حساب‌ها در پوشه `storage` نگهداری می‌شوند.

## راه‌اندازی در ویندوز

1. Node.js نسخه 20 یا جدیدتر را نصب کن.
2. فایل ZIP را استخراج کن و CMD را داخل پوشه `FileNex` باز کن.
3. وابستگی‌ها را نصب کن:

   ```cmd
   npm install
   ```

4. فایل تنظیمات را بساز:

   ```cmd
   copy .env.example .env
   ```

5. فایل `.env` را با Notepad باز کن. مقدارهای `ADMIN_UPLOAD_CODE` و `FILE_CODE_SECRET` را با دو مقدار تصادفی و متفاوت عوض کن. رمز مدیر باید حداقل ۱۶ کاراکتر و کلید مخفی حداقل ۳۲ کاراکتر باشد. کد ثبت‌نام به‌صورت پیش‌فرض `13931363` است.
6. سرور را اجرا کن:

   ```cmd
   npm start
   ```

7. در مرورگر وارد `http://localhost:3000` شو.

برای توقف سرور در CMD کلیدهای `Ctrl + C` را بزن.

## داشبوردها

- **داشبورد کاربر:** با «ورود / ثبت‌نام» وارد شو. هر کاربر هنگام ثبت‌نام باید کد ثبت‌نام را بداند.
- **داشبورد مدیر:** روی «داشبورد مدیر» بزن و مقدار `ADMIN_UPLOAD_CODE` را وارد کن. از بخش‌های کاربران، مدیران فعال، فایل‌ها و آپلود فایل استفاده کن.
- مدیران فعال به معنی نشست‌های مدیریتی باز در همین اجرای سرور است؛ این پروژه فعلاً حساب مدیریتی مستقل با نام کاربری ندارد.

## نکات مهم

- کد `13931363` کد ثبت‌نام مشترک است و به‌تنهایی احراز هویت قوی برای یک سرویس عمومی محسوب نمی‌شود. اگر سایت را عمومی می‌کنی، آن را تغییر بده و برای هر کاربر حساب مستقل نگه دار.
- نشست‌ها فعلاً در حافظه سرور نگهداری می‌شوند و با خاموش‌شدن سرور از بین می‌روند؛ برای استفاده عمومی بهتر است از پایگاه داده و ذخیره‌سازی نشست پایدار استفاده شود.
- داده‌ها و فایل‌ها در `storage` محلی هستند. برای استقرار عمومی از میزبانی Node.js با فضای ذخیره‌سازی پایدار، HTTPS، پشتیبان‌گیری و بررسی امنیتی استفاده کن.
- فایل `.env` را با کسی به اشتراک نگذار و آن را در GitHub آپلود نکن.
